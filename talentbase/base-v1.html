Вакансии

Профиль может существовать без вакансии и участвовать в нескольких вакансиях одновременно. Связь профиль ↔ вакансия имеет собственную recruiting-стадию и не меняет статус обработки профиля.

Импорт

Morning Runs · транспорт · история
Morning Runs

Каждое утро Scheduled Task собирает кандидатов по нескольким направлениям и передаёт записи в TalentBase. Один Morning Run содержит записи из разных направлений.

Внешняя запись не становится готовым профилем автоматически: валидация → нормализация → дедупликация по устойчивым идентификаторам → классификация → review при необходимости → создание или обновление одного профиля. Один человек = один профиль.

Направления профилей

Справочник направлений базы

Новое направление сразу появится в навигации, фильтрах, выборе направления профиля и в классификации Morning Runs.

Направление — сегмент профессиональной базы, а не должность и не отдел. Архив профиля — это статус обработки; архив направления — отдельная операция справочника.
